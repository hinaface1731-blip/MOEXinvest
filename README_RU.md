# MOEXinvest

Российский рынок в [Daily Stock Analysis](https://github.com/ZhuLinsen/daily_stock_analysis):
акции, ОФЗ, корпоративные облигации и индексы через официальный MOEX ISS.
Исходные возможности иностранных рынков сохранены.

**[Открыть публичную демонстрацию](https://hinaface1731-blip.github.io/MOEXinvest/)**

Демонстрация — снимок реальных публичных данных, обновляемый GitHub Actions.
Время сделки и получения показаны рядом с источником. Это не поток котировок в реальном времени.
Личный портфель, редактирование настроек, ключи и вызовы LLM доступны в серверной версии.

## Возможности

- Котировки и история OHLCV; биржевые идентификаторы, режимы торгов, кеш, повторы и пагинация.
- SMA/EMA, RSI, MACD, Bollinger, ATR, волатильность, просадка, сравнение с IMOEX.
- Полная цена облигации с НКД, купонный график, биржевая доходность, расчётная YTM и дюрация.
- Ключевая ставка, инфляция, валюты, календарь заседаний и новости Банка России.
- Рублёвые счета, покупки/продажи, комиссии, пополнения/выводы, дивиденды/купоны, CSV, XIRR, концентрация и календарь выплат.
- Русский интерфейс с темами и мобильной вёрсткой, отчёты и приватные Telegram-команды.
- Публичная Pages-сборка и ежедневные отчёты через Actions; Docker для личного приложения.

уже подтверждённые факты и риски. Прогнозы прибыли, брокерские подключения и торговые операции не выполняются.
